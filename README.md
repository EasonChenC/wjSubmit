# 问卷星自动化系统

## ⚠️ 重要声明

本项目仅用于**防御性安全研究**，目的是：
- 研究自动化攻击手段
- 开发相应的检测和防护机制
- 提升问卷平台的安全性

**禁止用于**：
- 制造虚假问卷数据
- 商业欺诈
- 学术造假
- 其他非法用途

## 安装步骤

### 1. 安装Python依赖

```bash
pip install -r requirements.txt
```

### 2. 安装Playwright浏览器

```bash
playwright install chromium
```

## 使用方法

### 基本使用

```bash
python main.py
```

按照提示选择任务规模：
- 小规模测试 (5-10份)
- 中等规模 (50-100份)
- 大规模 (500-1000份)
- 自定义数量

### 配置修改

编辑 `config.py` 文件修改配置：
- `QUESTIONNAIRE_URL`: 问卷链接
- `PERFORMANCE_CONFIGS`: 性能参数
- `BROWSER_CONFIG`: 浏览器设置
- `CAPTCHA_CONFIG`: 验证码配置
