## 任务一：识别量表题 vs 基础题

**量表题的核心定义**：通过一组有序等级选项，测量被调查者对某事物的**主观态度/感受/认知/心理程度**（如满意度、认同度、重要性、心理频率感受等），核心是"程度测量"而非"事实统计"。

**量表题的判断标准（必须同时满足）**：
1. 题干描述一种主观状态/态度/评价（如"我认为…""您对…满意吗""您觉得…重要吗"）
2. 选项表示**主观感受的强弱/多少程度**，且选项之间存在递进关系
3. 选项本身是**纯粹的程度词汇**，不含具体的客观数值/数量区间
   - ✅ 量表选项示例：非常不同意/不同意/一般/同意/非常同意；从不/很少/有时/经常/总是；很不满意/不满意/一般/满意/很满意；完全不重要/不重要/一般/重要/非常重要
   - ❌ 不是量表选项：每周3次以上/每周1-2次/每月2-3次/每月1次及以下（这是具体次数区间，测的是客观行为事实，不是主观感受）
4. 答案可以直接换算成分数用于计算均值/得分率

**关键陷阱（务必注意）**：选项即使呈递进排列，只要选项文本包含**具体的数字量级**（次数、时长、金额、年龄、频率区间等，如"1-2次""3-5次""6-10次""1小时以内""1-2小时""每周3次以上"），就属于**行为频次/统计分类题**，不是量表题——因为它测量的是可核实的客观事实数量，不是主观心理程度。即使这类题目只有4、5个选项且有大小顺序，也不能算量表题。

**基础题**（分类题/事实统计题）：
- 用于收集客观信息或事实：性别、年龄、职业、地区、行为发生的具体次数/频次/时长/金额等
- 选项要么无序（男/女），要么是具体数值区间的排列（1-2次/3-5次/6-10次，1小时以内/1-2小时/2-4小时）
- 即使选项有大小顺序，只要测的是可核实的客观数量而非主观感受，也归为基础题

**对比示例**：
- "您参加活动的频率（近三个月）" + 选项"每周3次以上/每周1-2次/每月2-3次/每月1次及以下/很少参加" → 选项是具体次数区间 → **基础题**（不是量表题）
- "您多久参与一次类似活动" + 选项"从不/很少/偶尔/经常/总是" → 选项是纯主观频率感受词，无具体数字 → **量表题**
- "您平均每月参与次数" + 选项"1-2次/3-5次/6-10次/10次以上" → 具体次数统计 → **基础题**
- "您每次活动的平均时长" + 选项"1小时以内/1-2小时/2-4小时/4小时以上" → 具体时长统计 → **基础题**

**量表题常见子类型**（均属于量表题，判断标准同上）：
- 李克特/同意度量表："非常不同意~非常同意"（如"我认为公司管理制度合理"）
- 满意度量表："非常不满意~非常满意"
- 重要性量表："完全不重要~非常重要"
- 主观频率量表："从不/很少/有时/经常/总是"（注意与"每周3次/每月1次"等客观次数区分，见上）
- 评价等级量表："很差/较差/一般/较好/很好"

**量表等级数不固定**：量表题选项数可以是4级（无中立选项，强迫选择）、5级（最常见，含中立）、7级或9级（更精细，常见于科研/心理测量）。**不要仅凭选项数量判断是否为量表题**——无论4/5/7/9个选项，只要满足上述判断标准（主观程度词+递进关系+无具体数值），都是量表题。

## 任务二：识别正向题与反向题（仅对量表题）

**正向题**：
- 题干和选项的"积极方向"一致
- 答题者选择更靠近"积极端"的
选项表示态度更积极
- 例："您对产品的满意度" + 选项"非常满意...非常不满意" → 选"非常满意"=积极

**反向题**：
- 题干为负向表述，需要反向编码（在数据分析时）
- 答题者选择更靠近"消极端"的选项才表示对题干的同意
- 例："您对产品感到失望" + 选项"非常同意...非常不同意" → 选"非常同意"=消极态度

## 任务三：识别每道量表题中的积极/消极选项值（仅对量表题）

根据题干文本+选项标签，判断：
- `positive_values`：表示积极态度/满意/同意/频繁/高满意度 等的选项value列表
- `negative_values`：表示消极态度/不满/不同意/很少/低满意度 等的选项value列表
- `neutral_values`：中立选项的value列表

**重要**：不能只靠选项在列表中的位置判断。必须通过选项标签文本理解其含义。
- 如"非常满意,比较满意,一般,不太满意,非常不满意" → positive=[1,2], neutral=[3], negative=[4,5]
- 但如果选项反序："非常不满意,不太满意,一般,比较满意,非常满意" → positive=[4,5], neutral=[3], negative=[1,2]
