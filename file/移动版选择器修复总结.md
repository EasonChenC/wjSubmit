# 移动版选择器修复总结

## 修复时间
2026-07-22

## 问题描述
测试失败，所有问题填写超时（Timeout 30000ms exceeded），原因是代码使用桌面版选择器，但问卷URL是移动版。

## 修复内容

### 1. 单选题（Q1, Q4, Q5, Q8）
**修改前：**
```python
await page.click(f'input[name="q1"][value="{answer}"]')
```

**修改后：**
```python
await page.click(f'#q1_{answer}')
```

### 2. 多选题（Q6, Q9）
**修改前：**
```python
await page.check(f'input[name="q6"][value="{option}"]')
```

**修改后：**
```python
await page.check(f'#q6_{option}')
```

### 3. Q3 城市输入（只读输入框）
**修改前：**
```python
await page.fill('input[name="q3"]', answer)
```

**修改后：**
```python
await page.evaluate(f'document.getElementById("q3").value = "{answer}"')
```

**原因：** 移动版使用只读输入框，点击后打开城市选择器弹窗，需要用JavaScript绕过只读限制

### 4. Q7 矩阵评分
**修改前：**
```python
await page.fill(f'input[name="{q_id}"]', answer)
```

**修改后：**
```python
await page.click(f'tr[fid="{q_id}"] a[dval="{answer}"]')
```

**原因：** 移动版使用点击评分元素来设置隐藏字段的值

### 5. Q10 满意度评分（1-5分）
**修改前：**
```python
await self._fill_rating_question(page, 'div10', answer, max_rating=5)
```

**修改后：**
```python
await page.click(f'#div10 a.rate-off[val="{answer}"]')
```

### 6. Q11 NPS推荐度（0-10分）
**修改前：**
```python
await self._fill_rating_question(page, 'div11', answer, max_rating=10)
```

**修改后：**
```python
await page.click(f'#div11 a.rate-off[val="{answer + 1}"]')
```

**注意：** `val` 属性从 1-11 对应分数 0-10

### 7. Q12 排序题
**修改前：**
```python
await self._fill_sort_question(page, answer)
```

**修改后：**
```python
for option_value in answer:
    await page.click(f'#div12 li.ui-li-static[serial="{option_value}"]')
    await asyncio.sleep(0.3)
```

### 8. Q13/Q14 文本输入
**修改前：**
```python
await page.fill('input[name="q13"]', answer)
await page.fill('textarea[name="q14"]', answer)
```

**修改后：**
```python
await page.fill('#q13', answer)
await page.fill('textarea#q14', answer)
```

## 代码清理
删除了不再使用的辅助方法：
- `_fill_rating_question()`
- `_fill_sort_question()`

这些方法被内联到 `_fill_by_type()` 中，使用更精确的移动版选择器。
