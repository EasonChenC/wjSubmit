## 关键发现

### 1. 移动版结构特点

移动版使用 **jQuery Mobile** 框架，具有以下特点：

- **单选题**：使用 `<a class="jqradio">` 标签包装的自定义样式，实际的 `<input type="radio">` 是隐藏的
- **多选题**：使用 `<a class="jqcheck">` 标签包装的自定义样式，实际的 `<input type="checkbox">` 是隐藏的
- **下拉选择**：使用 Select2 插件，真实的 `<select>` 元素存在
- **文本输入**：真实的 `<input type="text">` 和 `<textarea>` 元素存在
- **评分题**：使用 `<a class="rate-off">` 标签，带 `val` 属性，更新隐藏的 `<input type="hidden">`
- **排序题**：使用 `<li class="ui-li-static">` 元素，带 `serial` 属性，隐藏的 `<input type="hidden">`

## 各题型选择器分析

### Q1: 性别（单选）

**HTML 结构：**
```html
<div class="ui-radio">
    <span class="jqradiowrapper">
        <input type="radio" value="1" id="q1_1" name="q1" />
        <a class="jqradio" href="javascript:;"></a>
    </span>
    <div class="label" for="q1_1">男</div>
</div>
```

**正确选择器：**
```python
# 方法1：点击隐藏的 input（推荐）
await page.click(f'#q1_{answer}')

# 方法2：通过 JavaScript 设置 checked
await page.evaluate(f'document.getElementById("q1_{answer}").checked = true')

# 方法3：点击可视化的 jqradio 元素
await page.click(f'label[for="q1_{answer}"] ~ span .jqradio')
```

## 总结

### 移动版 vs 桌面版主要差异

| 题型 | 桌面版选择器 | 移动版选择器 |
|------|-------------|-------------|
| 单选 | `input[name="q1"][value="1"]` | `#q1_1` |
| 多选 | `input[name="q6"][value="1"]` | `#q6_1` |
| 下拉 | `select[name="q2"]` | `select[name="q2"]` (相同) |
| 文本 | `input[name="q3"]` | `#q3` (需要 JS 绕过只读) |
| 评分 | 复杂的 div 结构 | `a.rate-off[val="X"]` |
| 矩阵 | 复杂的 table 结构 | `tr[fid="q7_X"] a[dval="Y"]` |
| 排序 | 复杂的拖拽 | `li[serial="X"]` 点击排序 |

### 关键修复点

1. **单选/多选题**：从 `name+value` 选择器改为 `ID` 选择器
2. **Q3 城市**：需要用 JavaScript 绕过 readonly 限制
3. **Q7 矩阵**：使用 `tr[fid] a[dval]` 选择器
4. **Q10 评分**：使用 `#div10 a[val]` 选择器
5. **Q11 NPS**：注意 val 属性比实际分数大1
6. **Q12 排序**：按顺序点击 `li[serial]` 元素
