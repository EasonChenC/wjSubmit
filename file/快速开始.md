# 快速开始指南

## 环境准备

### 1. 检查Python版本
```bash
python --version
# 需要 Python 3.10 或更高版本
```

### 2. 安装依赖
```bash
# 安装Python包
pip install -r requirements.txt

# 安装Playwright浏览器
playwright install chromium
```

## 运行项目

### 第一次运行（测试）

建议第一次运行时选择小规模测试：

```bash
python main.py
```

选择选项 `1` (小规模测试)，提交 5-10 份问卷进行测试。

### 配置说明

在 `config.py` 中可以修改：

```python
# 修改目标问卷URL
QUESTIONNAIRE_URL = 'https://v.wjx.cn/vm/rqKTYry.aspx'

# 浏览器配置
BROWSER_CONFIG = {
    'headless': False,  # False=显示浏览器窗口，True=无头模式
    'slow_mo': 0,       # 放慢操作速度（毫秒）
}

# 验证码配置
CAPTCHA_CONFIG = {
    'solver_type': 'behavioral',  # 行为模拟方式
    'retry_times': 3,             # 失败重试次数
}
```

## 使用流程

1. **启动程序**
   ```bash
   python main.py
   ```

2. **选择规模**
   - 选项 1: 小规模测试 (5-10份) - 用于测试
   - 选项 2: 中等规模 (50-100份) - 日常使用
   - 选项 3: 大规模 (500-1000份) - 大批量
   - 选项 4: 自定义数量

3. **监控进度**
   - 程序会每5秒显示进度信息
   - 显示成功/失败数量
   - 显示当前速率和预计剩余时间

4. **查看结果**
   - 任务完成后会显示统计摘要
   - 成功数量、失败数量、总耗时等

## 常见问题

### Q1: 提示 "playwright not found"
```bash
# 解决方法：
playwright install chromium
```

### Q2: 验证码通过率低
- 调整验证码策略：修改 `config.py` 中的 `CAPTCHA_CONFIG`
- 考虑使用人工打码平台（需要额外开发）

### Q3: 浏览器启动失败
- 检查是否正确安装了 Playwright
- 尝试使用管理员权限运行

### Q4: 速度太慢
- 增加并发数：修改 `PERFORMANCE_CONFIGS` 中的 `concurrent_workers`
- 注意：并发数过高可能导致被检测

### Q5: 想查看浏览器操作过程
```python
# 在 config.py 中设置
BROWSER_CONFIG = {
    'headless': False,  # 改为 False
}
```

## 进阶使用

### 自定义答案生成逻辑

编辑 `core/answer_generator.py`，修改 `generate_answers` 方法中的答案生成逻辑。

### 针对特定问卷调整

1. 查看问卷的HTML结构
2. 修改 `core/submitter.py` 中的 `_fill_by_type` 方法
3. 调整元素选择器以匹配实际的HTML结构

### 添加代理支持

1. 实现 `proxy/proxy_pool.py` 模块
2. 在 `core/browser_manager.py` 的 `_get_proxy` 方法中集成代理池

## 调试技巧

### 启用详细日志
```python
# 在 main.py 开头添加
import logging
logging.basicConfig(level=logging.DEBUG)
```

### 单步调试
- 将 `BROWSER_CONFIG['slow_mo']` 设置为较大值（如1000）
- 设置 `headless=False` 观察浏览器操作

### 测试单个提交
```python
# 创建测试脚本 test.py
import asyncio
from core.browser_manager import BrowserManager
from core.answer_generator import AnswerGenerator
from core.captcha_solver import CaptchaSolver
from core.submitter import QuestionnaireSubmitter

async def test():
    browser_manager = BrowserManager(pool_size=1)
    await browser_manager.initialize()

    submitter = QuestionnaireSubmitter(
        url='your_url_here',
        answer_generator=AnswerGenerator(),
        captcha_solver=CaptchaSolver(),
        browser_manager=browser_manager
    )

    result = await submitter.submit_one()
    print(result)

    await browser_manager.cleanup()

asyncio.run(test())
```

## 性能优化建议

1. **小规模测试** (< 100份)
   - 并发数：5-10
   - 无需代理

2. **中等规模** (100-1000份)
   - 并发数：20-30
   - 建议使用代理

3. **大规模** (> 1000份)
   - 并发数：50+
   - 必须使用代理池
   - 考虑分布式部署
